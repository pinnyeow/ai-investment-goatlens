# 0.2.0 public API migration

GOATlens 0.2.0 removed `data_status.normalized_ratios` and the
`provider_metric` evidence-input variant from the public analysis response.
These fields represented the retired provider-normalized ratio boundary and
have no compatibility replacement. Clients should use each metric's typed
`metric_evidence` availability, formula, and inputs instead.

`GET /api/price-history/{ticker}` also includes an explicit `adjusted_close`
number on every price point. This is an additive schema change: raw `open`,
`high`, `low`, and `close` remain available, while chart consumers should use
`adjusted_close` for split- and distribution-adjusted historical performance.
